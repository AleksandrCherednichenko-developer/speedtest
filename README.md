# speedtest

Консольный скрипт на Node.js для замера скорости скачивания. Делает 10 последовательных запросов к указанному адресу, каждый раз дожидается полного ответа, затем выводит среднее время запроса, общий объём скачанных данных и скорость скачивания.

Внешних зависимостей нет: используются встроенные `fetch`, `AbortSignal` и `performance.now()`.

## Требования

- Node.js 20.3 или новее (проверено на 24)

## Запуск

```bash
git clone https://github.com/AleksandrCherednichenko-developer/speedtest.git
cd speedtest
node index.js <url>
```

Пример:

```bash
node index.js https://proof.ovh.net/files/10Mb.dat
```

Через npm:

```bash
npm start -- https://proof.ovh.net/files/10Mb.dat
```

### Опции

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `--count N` | 10 | число замеряемых запросов |
| `--warmup N` | 0 | прогревочные запросы до замера, в статистику не попадают |
| `--timeout MS` | 30000 | лимит на один запрос в миллисекундах |
| `--json` | — | вывести результат в JSON (для скриптов) |
| `-h`, `--help` | — | справка |

Ctrl+C во время работы прерывает текущий запрос и печатает итог по уже завершённым. Повторное нажатие завершает скрипт сразу.

## Единицы измерения

| Величина | Единица | Определение |
|---|---|---|
| Время запроса | миллисекунды (мс) | от отправки запроса до получения последнего байта тела |
| Объём данных | мегабайты (МБ) | 1 МБ = 1 000 000 байт |
| Скорость | мегабиты в секунду (Мбит/с) | 1 Мбит = 1 000 000 бит, как у провайдеров и speedtest-сервисов |

Итоговая скорость = `(всего байт × 8) / (суммарное время запросов в секундах) / 1 000 000`.
Дополнительно выводятся медиана, минимум и максимум времени и скорости по отдельным запросам: медиана устойчивее к единичным выбросам, чем среднее.

## Пример вывода

```
URL: https://proof.ovh.net/files/10Mb.dat
Запросов: 3 (+1 прогревочных), таймаут: 30000 мс

прогрев    3992.4 мс     10.49 МБ     21.01 Мбит/с
# 1        3677.3 мс     10.49 МБ     22.81 Мбит/с
# 2        4093.6 мс     10.49 МБ     20.49 Мбит/с
# 3        4509.2 мс     10.49 МБ     18.60 Мбит/с

Итого
  Успешных запросов:     3 из 3
  Скачано всего:         31.46 МБ
  Среднее время запроса: 4093.4 мс
  Время (медиана/мин/макс): 4093.6 / 3677.3 / 4509.2 мс
  Скорость (медиана/мин/макс): 20.49 / 18.60 / 22.81 Мбит/с
  Скорость скачивания:   20.49 Мбит/с
```

Во время скачивания в терминале показывается, сколько уже загружено. Прогресс пишется в stderr, поэтому не попадает в `--json` и в перенаправленный вывод.

## Коды выхода

| Код | Когда |
|---|---|
| 0 | хотя бы один запрос успешен |
| 1 | неверные аргументы или ни один запрос не удался |
| 130 | прервано по Ctrl+C (есть частичный итог) |

## Тесты

```bash
npm test
```

Тесты на встроенном `node:test` поднимают локальный HTTP-сервер, поэтому интернет для них не нужен. Покрыты разбор аргументов, статистика, подсчёт байтов, HTTP-ошибки, таймаут, отмена и поведение CLI, включая Ctrl+C и `--json`.

## Структура

- `index.js` — CLI: аргументы, вывод, Ctrl+C
- `lib.js` — логика замера и статистика без привязки к консоли
- `test/` — тесты и локальный тестовый сервер

## Как это работает

- Запросы идут строго по одному: следующий начинается после того, как тело предыдущего прочитано целиком.
- Объём считается по фактически полученным байтам из потока ответа, а не по заголовку `Content-Length`.
- Отправляется `Cache-Control: no-cache`, чтобы не получать ответ из промежуточного кэша.
- Запрос с ошибкой (сеть, таймаут, HTTP-статус не 2xx) выводится в лог и в статистику не попадает.
- Во время запроса входят DNS, TCP/TLS-рукопожатие и ожидание первого байта, поэтому на маленьких файлах скорость получится заниженной. Лучше брать файл от 10 МБ; первый запрос можно исключить флагом `--warmup 1`.
